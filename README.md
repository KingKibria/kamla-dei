# Kamla Dei — পার্সোনাল AI এজেন্ট প্ল্যাটফর্ম

**Kamla Dei** হলো PC-র জন্য একটি পার্সোনাল AI এজেন্ট: ব্যবহারকারী চ্যাটে যেভাবে কথা বলে, এজেন্ট ঠিক সেভাবেই বুঝে তার নিজের কম্পিউটারে কাজ করে দেয় — ফাইল বানানো/গোছানো, কোড লেখা, ওয়েব সার্চ, সিস্টেম তথ্য — প্রতিটা ঝুঁকির কাজে আগে অনুমতি নিয়ে, পুরো অডিট লগ রেখে।

## যা আছে

- **২২টি টুল** — READ / WRITE / RISK তিন স্তরের অনুমতি মডেল; RISK কাজে প্রতিবার approval, deny-list হার্ড-কোডেড, kill switch
- **Brain Router** — সাধারণ কাজে Groq, ভারী কাজে Xkiro; প্রতিটা provider-এ key-pool (round-robin + cooldown), key না থাকলে অফলাইন ডেমো মোড
- **Token Saver + 🪙 per-task টোকেন মিটার** — প্রতিটা কাজে কত টোকেন খরচ হলো সাথে সাথে দেখা যায়
- **লাইসেন্সিং** — KD-XXXX-XXXX-XXXX access key, প্ল্যান (Free / Pro / Family), নিজের সার্ভার থেকে বিতরণ (Play Store নয়)
- **PC Bridge** — হোস্টেড UI থেকে লোকাল ইঞ্জিনে (127.0.0.1:8790) সংযোগের ব্যবস্থা: discovery + key-যাচাই

## চালানো

1. `SETUP-KEY.bat` — নিজের Groq / Xkiro key বসাও (key কখনো চ্যাটে পাঠাবে না)
2. `START.bat` — ইঞ্জিন চালু হয়ে ব্রাউজারে UI খুলবে (port 8790)

## গঠন

- `server/` — Python (stdlib-only) সার্ভার + এজেন্ট ইঞ্জিন (`engine/`: brain router, tool loop, ২২ টুল, মেমরি)
- `web/` — চ্যাট UI (poll-based), approval কার্ড, ফাইল প্যানেল, ভয়েস
- `docs/` — প্রোডাক্ট ব্লুপ্রিন্ট ও মাস্টার প্রম্পট

## নীতি

শুধু ethical কাজ। অনুমতি ছাড়া কোনো ডেটা মেশিন ছেড়ে যায় না — কোন ডেটা বাইরে যায়, তার plain-language ব্যাখ্যা প্রোডাক্টের অংশ।
